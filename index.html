About This Website

This is a basic HTML version of a task allocation system developed to improve team organisation and accountability.

About Me

I am currently studying Software Engineering and learning how to create websites using HTML for Web Technologies.

I work in a warehouse Flow Room, where organisation, teamwork and communication are important parts of my role.

Why I Created This Website

I decided to create a Task Allocation Website inspired by a project I have been developing for my workplace.

The main purpose is to help improve organisation and accountability within a team.

Website Features

  • Display daily tasks
  • Assign responsibilities to team members
  • Show task deadlines
  • Display task completion status
  • Help organise daily shift activities

What I Want to Learn

I would like to improve my HTML skills before moving on to more advanced CSS and JavaScript. My goal is to eventually create a fully functional task management application.
